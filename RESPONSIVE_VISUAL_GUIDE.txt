================================================================================
                   THE TECHNICAL APPROACH
================================================================================

CSS Transform Scale Method:
  - Keeps original dimensions (1400px × 700px)
  - Uses CSS transform: scale() to shrink it
  - Benefits:
    * Maintains perfect proportions
    * Smooth animations preserved
    * No layout recalculation needed
    * Better performance
    * Same visual appearance, just smaller

Before (Bad):
  @media (max-width: 768px) {
    width: 700px;    ← Changes dimensions
    height: 350px;   ← Stretches/compresses proportions
  }

After (Good):
  @media (max-width: 768px) {
    width: 1400px;
    height: 700px;
    transform: scale(0.65);  ← Proportional zoom
    transform-origin: center center;
  }
