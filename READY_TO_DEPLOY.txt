🎯 YOUR DEPLOYMENT CHECKLIST
================================================================================

STEP 1: Secure Admin Account (2 minutes)
  → Go to http://localhost:3001/admin.html
  → Login: admin / admin123
  → Change password in Security tab
  → Save new password safely

STEP 2: Generate Secret Key (1 minute)
  → Visit https://randomkeygen.com/
  → Copy the 128-bit WEP Key
  → Save this value

STEP 3: Push to GitHub (3 minutes)
  → Open terminal
  → Run: git add .
  → Run: git commit -m "Portfolio ready to deploy"
  → Run: git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
  → Run: git branch -M main
  → Run: git push -u origin main

STEP 4: Deploy on Render (5 minutes)
  → Go to https://render.com
  → Sign up with GitHub
  → Create Web Service from your repository
  → Configure: npm install & npm start
  → Add environment variables (PORT, NODE_ENV, SECRET_KEY)

STEP 5: Test (5 minutes)
  → Visit your Render URL
  → Check gallery works
  → Click a project
  → Go to /admin.html and login
  → Test contact form

TOTAL TIME: ~20 minutes ⏱️

🌐 DEPLOYMENT PLATFORM: RENDER (Recommended)
================================================================================

Why Render?
✅ Free tier available
✅ Easy GitHub integration
✅ Automatic HTTPS/SSL
✅ Auto-deploys on push
✅ Simple environment variables
✅ Good for Node.js apps

Free Tier Note:
- Spins down after 15 min of inactivity (wakes on request)
- First request after sleep takes ~30 sec
- Paid tier ($7/month) for always-on hosting

🚀 QUICK START
================================================================================

Ready to go live NOW? Follow this:

1. Open terminal in your portfolio folder
2. Run:
   git add .
   git commit -m "Ready to deploy"
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git branch -M main
   git push -u origin main

3. Go to Render.com
4. Create Web Service
5. Connect GitHub repository
6. Set environment variables:
   PORT=3001
   NODE_ENV=production
   SECRET_KEY=[your-generated-key]
   GMAIL_USER=disabled

7. Deploy!
8. Test at your public URL
9. Share with the world!
