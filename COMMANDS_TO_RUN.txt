================================================================================
                    COPY-PASTE THESE COMMANDS
================================================================================

Press Windows+R, type "cmd" and Enter to open Command Prompt.

Then paste these commands ONE AT A TIME, pressing Enter after each:

================================================================================
COMMAND 1: Navigate to project
================================================================================

cd /d C:\Users\SARRA\Downloads\portSarra

================================================================================
COMMAND 2: Initialize Git
================================================================================

git init

================================================================================
COMMAND 3: Set Git user name
================================================================================

git config user.name "Portfolio"

================================================================================
COMMAND 4: Set Git email
================================================================================

git config user.email "portfolio@local"

================================================================================
COMMAND 5: Add all files
================================================================================

git add .

================================================================================
COMMAND 6: Commit to Git
================================================================================

git commit -m "Initial portfolio"

================================================================================
AFTER THIS, GO TO GITHUB
================================================================================

1. Go to https://github.com/new
2. Create new repository named "portfolio"
3. Copy the URL it gives you (https://github.com/yourname/portfolio.git)

================================================================================
COMMAND 7: Add GitHub remote (REPLACE URL BELOW)
================================================================================

git remote add origin https://github.com/YOUR_USERNAME/portfolio.git

================================================================================
COMMAND 8: Rename branch to main
================================================================================

git branch -M main

================================================================================
COMMAND 9: Push to GitHub (WAIT 2 MINUTES FOR THIS)
================================================================================

git push -u origin main

================================================================================
AFTER PUSH SUCCEEDS, GO TO RENDER
================================================================================

1. Go to https://render.com
2. Click "New +"
3. Click "Web Service"
4. Connect GitHub
5. Select "portfolio" repo
6. Fill:
   - Name: portfolio
   - Runtime: Node
   - Build: npm install
   - Start: npm start
7. Click Create

DONE! Wait 2-5 minutes, then check your public URL!
