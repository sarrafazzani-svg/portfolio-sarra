================================================================================
                            NEED HELP?
================================================================================

Most common issues:

Q: "fatal: not a git repository"
A: Make sure you ran "git init" first

Q: "fatal: origin already exists"
A: Run: git remote remove origin
   Then run: git remote add origin <url>

Q: "My site doesn't load"
A: Wait 5 minutes after Render "Create Web Service"
   Render takes time to build and start the server

Q: "Admin login doesn't work"
A: Use your new password (not "admin123")
   Check .env file has SECRET_KEY

Q: "Gallery doesn't work on live site"
A: Verify all .html, .js, .css files are in Git
   Run: git add .
        git commit -m "Fix"
        git push origin main
   Wait 1 minute for Render to auto-deploy
