🎯 YOUR MISSION: Make portfolio public and live in 15 minutes

═══════════════════════════════════════════════════════════════════════════════
STEP 1: GITHUB (5 minutes)
═══════════════════════════════════════════════════════════════════════════════

Create repository:
  1. Go to https://github.com/new
  2. Name: "portfolio"
  3. Click "Create"
  4. Copy URL shown

Push code to GitHub:
  Open terminal in your project folder and run:
  
  git init
  git add .
  git commit -m "Initial portfolio commit"
  git branch -M main
  git remote add origin YOUR-URL-HERE
  git push -u origin main
  
  (Replace YOUR-URL-HERE with the URL from step 1)

═══════════════════════════════════════════════════════════════════════════════
STEP 2: RENDER DEPLOYMENT (5 minutes)
═══════════════════════════════════════════════════════════════════════════════

1. Go to https://render.com
2. Sign up with GitHub (click "Sign up with GitHub")
3. Click "New +" → "Web Service"
4. Select your "portfolio" repository
5. Fill in:
   Name: portfolio-site
   Environment: Node
   Build Command: npm install
   Start Command: npm start
   Plan: Free
6. Click "Create Web Service"
7. Wait for deployment (watch the logs)
8. When done, you'll see: "Your service is live" ✅

═══════════════════════════════════════════════════════════════════════════════
STEP 3: TEST & CONFIGURE (5 minutes)
═══════════════════════════════════════════════════════════════════════════════

Test your site:
  Visit: https://portfolio-site.onrender.com
  Should see your portfolio!

Configure admin:
  Visit: https://portfolio-site.onrender.com/admin.html
  Login: admin / admin123
  Go to 🔐 Security → Change password

Add first project:
  Admin → 📋 Projects → + Add New
  Fill in details, upload images
  Click Save → Appears on live site immediately!

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Blank page?
  → Wait 5 minutes for deployment
  → Hard refresh: Ctrl+Shift+R
  → Check Render dashboard for errors

Admin login fails?
  → Use correct credentials: admin / admin123
  → Try incognito window
  → Check .admin-credentials.json file

Projects don't show?
  → Click "Save Project" (not just fill form)
  → Refresh browser (Ctrl+F5)
  → Check Admin → Projects to verify saved
