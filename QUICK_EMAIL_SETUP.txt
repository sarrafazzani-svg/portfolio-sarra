🚀 QUICK EMAIL SETUP (3 EASY STEPS)

STEP 1: Get Gmail App Password
================================
1. Go to: https://myaccount.google.com/security
2. Enable "2-Step Verification" (if not already enabled)
3. Click "App passwords"
4. Select: Windows Computer + Mail
5. Copy the 16-character password (like: xxxx xxxx xxxx xxxx)


STEP 2: Create .env File
================================
1. Open Notepad
2. Paste this:
   GMAIL_USER=your-email@gmail.com
   GMAIL_PASSWORD=xxxx xxxx xxxx xxxx

3. Replace:
   - "your-email@gmail.com" with YOUR Gmail
   - "xxxx xxxx xxxx xxxx" with YOUR app password from Step 1

4. Save as: .env
   Location: C:\Users\SARRA\Downloads\portSarra\.env
   
   IMPORTANT: Make sure it says ".env" not ".env.txt"
   - In Notepad: File → Save As
   - Filename: .env
   - Save type: All Files (*.*)


STEP 3: Restart Server
================================
1. Open Command Prompt
2. Type: cd C:\Users\SARRA\Downloads\portSarra
3. Type: node server.js
4. Should see: ✅ Email service ready

✨ DONE! Now test it:

- Go to: http://localhost:3001/index.html
- Scroll to Contact section
- Fill and submit the form
- Check your Gmail inbox! 📧


TROUBLESHOOTING:
================
❌ ".env.txt" instead of ".env"?
   → Rename it: right-click → rename to .env

❌ "Email service ready" not showing?
   → Check .env file location
   → Check Gmail/password are correct
   → Restart server

❌ "2-Step Verification" not enabled?
   → Enable it first: https://myaccount.google.com/security

✅ Working? You're all set! Clients can now contact you! 🎉
