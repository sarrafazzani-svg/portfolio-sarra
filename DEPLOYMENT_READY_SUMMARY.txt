IMAGE LOADING IMPROVEMENTS
================================================================================

Image Path Handling:
  • Data URLs: Used as-is (base64 encoded images)
  • Full URLs: http/https URLs passed directly
  • Upload paths: "uploads/..." paths maintained
  • Relative files: Prepends "./" for root directory files

Fallback Strategy:
  • Arc items: Gray background (var(--gray-200))
  • Project cards: Gradient fallback (gray-200 to gray-100)
  • Prevents layout shift if images fail to load
  • Page remains usable even without images
